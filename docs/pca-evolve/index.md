Create and extend content—also called **PCA Evolve**—is the Creator workspace for
authoring governed resources. New resources are saved as Draft. Saving is not the same
as submitting for review.

## Follow the authoring path

1. Read [Prepare to create content](prepare-to-create-content.md).
2. Use [Choose a content workflow](choose-an-evolve-workflow.md).
3. Complete the domain guide for reference data, CFIHOS+, IMF, or symbols.
4. [Work with the Draft and submit it](drafts-and-submission.md).

The preparation guide covers access, duplicate searches, collection ownership, common
fields, evidence, and visibility, so those checks are not repeated on every workflow
page. Once you choose a resource family, its domain guide explains both the **Create**
workspace and the corresponding Creator API.

All successful creations begin as discoverable Drafts. Use the returned IRI to inspect
and revise the resource, and submit it only when it is complete. Saving and submitting
are separate operations.
