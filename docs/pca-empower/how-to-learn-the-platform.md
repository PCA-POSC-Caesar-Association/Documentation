Choose the shortest path that matches your task.

## Suggested learning path

1. Everyone: [Find and understand data](../pca-explore/index.md) and learn to read status.
2. Reader or developer: [Identifiers and representations](../pca-consume/formats-and-identifiers.md), then [API retrieval](../pca-consume/get-content-through-the-api.md).
3. Creator: [Prepare to create content](../pca-evolve/prepare-to-create-content.md), choose a domain workflow, then learn Draft submission.
4. Reviewer: learn Creator output first, then [Review and approve changes](../pca-govern/index.md) and the Governance process.
5. Collection owner: [Plan a hosted collection](../pca-host/get-started-with-hosting.md) before minting final PCA identifiers.

Learn the content ecosystem before creating something new, and use the human-readable
views before automating an API integration. Review, provenance, identifiers, and hosting
are part of the content lifecycle rather than optional technical details. Practice in
the environment supplied by PCA; hosts and roles do not automatically transfer between
environments. If the next step requires access, continue to
[Get access and support](get-access-and-support.md).
